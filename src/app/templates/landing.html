“Can a large language model warm-start classical metaheuristics to converge faster on truss sizing — while staying IS 800-compliant?”

The central research question of this thesis. Answered quantitatively across four benchmarks and five contributions.

Abstract

Two paragraphs for someone with five minutes.

Steel-truss sizing optimisation under IS 800:2007 is classically solved with evolutionary metaheuristics whose inner loops spend virtually all wall-clock time inside a finite-element solver. This thesis develops an integrated Python framework that composes classical evolutionary optimisation (GA, PSO, NSGA-II) with three modern AI layers — a neural surrogate, a reinforcement-learning agent, and a large-language-model warm-start designer — into one reproducible system, validated against four canonical benchmarks: the 10-bar planar, 25-bar spatial, 72-bar spatial tower, and 200-bar planar stepped tower.

The framework matches Sunar & Belegundu (1991) on 10-bar to 0.004 %; a three-hidden-layer MLP surrogate achieves R2 = 0.9993 on weight and a 132× wall-clock speedup; an LLM warm-start reduces generations-to-convergence on 10-bar by 36.8 % at paired-Wilcoxon p = 0.0046 across 40 seeds; and a rigorous re-run of the 72-bar spatial tower exposes that the literature-cited optima are infeasible by 22–62 % under hard-constraint enforcement — a methodological correction to the published literature.

The framework

Eight layers, one dataflow.

Each layer is a deliberate design choice; each layer sits behind a clean Python interface; each layer is exercised by at least one test in the 81-test suite.

L1

Benchmarks

10-bar, 25-bar, 72-bar, 200-bar — pinned geometry, loads, and bounds (Appendix C).

src/benchmarks/
L2

FEM kernel

Linear-elastic truss solver, partition-method boundary conditions, dense O(n3) solve (Appendix A).

src/fem/
L3

IS 800:2007 compliance

Clauses 3.8 slenderness, 6.2/6.3 tension, 7.1 Perry-Robertson compression, 5.6.1 deflection (Appendix B).

src/constraints/
L4

Metaheuristics

GA, PSO, NSGA-II via pymoo. Hard-constraint tournament; no soft penalties.

src/algorithms/
L5

Neural surrogate

MLP [256, 128, 64] trained on 10k LHS samples. Drop-in FEM replacement, with FEM fallback on screen failure.

src/ml/
L6

Reinforcement learning

PPO agent, multiplicative sizing action, 0.2 s inference latency.

src/rl/
L7

LLM warm-start

Claude Opus / Sonnet seeds the first population with reasoning and a confidence score. All responses cached.

src/llm/
L8

FastAPI + Streamlit UI

This page plus localhost:8501: the design aid a practitioner actually uses.

src/app/
